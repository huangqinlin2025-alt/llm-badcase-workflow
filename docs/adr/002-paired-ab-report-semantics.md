# ADR-002：购物神评成对 AB 报告以工作表标识定义语义

- 状态：接受
- 日期：2026-09-06

## 背景

`购物神评首轮hy_vs_claude_v3_106 (2).xlsx` 是多工作表报告。文件名与工作表模型/Prompt 标识不完全一致，且原始 Pointwise 页的 `case ID` 不能直接作为 A/B 配对键。依赖文件名或原始评分页的通用启发式会产生错误侧别和错误配对。

## 决策

该报告使用 `详细配对结果` 工作表作为受控导入源，以两组列头定义最终语义：

- A：`HY-Vision-2.0-instruct`，优化后 Prompt。
- B：`quinta_gouwushenping_firstround`，优化前 Prompt。

每个详细配对行拆为两条标准记录；配对行号用于该报告内配对，模型/Prompt 列标识、提示词阶段、加权总分、差值、胜出方、维度分数和理由作为证据保存。`evaluation_version` 仍由导入请求显式提供。

## 后果

后续 AB 信号可稳定解释“优化后 A 相对优化前 B”的效果，避免从文件名推断。此映射仅适用于已确认的购物神评报告；其他报告必须配置独立映射并增加回归测试，不能自动套用。
