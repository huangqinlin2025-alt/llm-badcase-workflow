## 手工验收

1. 从 GitHub Pages 打开当前 UI，上传三份真实样例，确认页面显示后端返回的真实解析、对齐、判定和同步状态。
2. 对一条候选采纳、另一条驳回；刷新页面和重启服务后确认审核状态仍存在。
3. 在企微大库核验稳定键、自动字段和审核字段；在小库核验仅采纳项存在且不重复。
4. 模拟企微写入异常，确认页面显示“待同步”，然后运行对账/重试直至恢复。
5. 检查日志、页面和 Git 历史，确认没有 Token、内部 ID 或用户原文泄露。
